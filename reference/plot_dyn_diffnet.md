# Plot the dynamic differential network

Plot the dynamic differential network

## Usage

``` r
plot_dyn_diffnet(grn, tfs, only_TFs = TRUE, order = NULL)
```

## Arguments

- grn:

  the dynamic network

- tfs:

  TFs

- only_TFs:

  whether or not to only plot TFs and exclude non-regulators

- order:

  the order in which to plot epochs, or which epochs to plot

## Value

plot
