# Computes mean expression of groups of genes in a dynamic network

Computes mean expression of groups of genes in a dynamic network

## Usage

``` r
mean_subnetwork_expression(matrix, community_list)
```

## Arguments

- matrix:

  genes-by-cells expression matrix

- community_list:

  list of dataframes with community assginemnts. Each dataframe is the
  result of running subnets.

## Value

subnetwork expression
