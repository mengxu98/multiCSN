# Get fitted coefficients

Get fitted coefficients

## Usage

``` r
# S3 method for class 'CSNObject'
coef(object, network = DefaultNetwork(object), celltypes = NULL, ...)
```

## Arguments

- object:

  CSNObject object

- network:

  Name of the network to use.

- celltypes:

  Celltypes to plot.

- ...:

  Other parameters

## Value

Return the fitted coefficients
