# Partition pseudotime states by density intersections

Partition pseudotime states by density intersections

## Usage

``` r
density_points(
  object = NULL,
  pseudotime_column = "pseudotime",
  group_column = NULL,
  meta_data = NULL,
  store = TRUE,
  overwrite = FALSE,
  posterior_threshold = 0.8,
  n_grid = 512,
  n_boot = 50,
  bandwidth = "nrd0",
  plot = FALSE,
  verbose = TRUE
)
```

## Arguments

- object:

  A `Seurat` object or a metadata `data.frame`.

- pseudotime_column:

  Column name containing pseudotime values.

- group_column:

  Optional metadata column containing ordered groups. When `NULL`, the
  function reuses `celltype`, `seurat_clusters`, `cluster`, or `group`
  when available.

- meta_data:

  Deprecated alias of `object` for backwards compatibility.

- store:

  Logical. When `object` is a `Seurat` object, store the partition
  result in `object@tools`.

- overwrite:

  Logical. Overwrite an existing stored partition.

- posterior_threshold:

  Maximum pairwise posterior dominance allowed inside a transition
  window. Lower values make transition windows narrower.

- n_grid:

  Number of grid points used for kernel density evaluation.

- n_boot:

  Number of bootstrap resamples used to assess boundary stability.

- bandwidth:

  Bandwidth passed to
  [`stats::density()`](https://rdrr.io/r/stats/density.html).

- plot:

  Logical. When `TRUE`, call
  [`plot_states()`](https://mengxu98.github.io/multiCSN/reference/plot_states.md)
  after computing the partition.

- verbose:

  Logical.

## Value

If `object` is a `Seurat` object, returns the updated object. Otherwise
returns the partition result list.
