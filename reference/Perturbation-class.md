# The Perturbation class

The Perturbation object stores the original expression matrix, perturbed
expression matrix, TF states, prediction results, and embedding results.

## Slots

- `original`:

  A matrix.

- `perturbed`:

  A matrix.

- `tf_states`:

  A dataframe.

- `prediction`:

  A list.

- `embedding`:

  A matrix.

- `params`:

  A list.
