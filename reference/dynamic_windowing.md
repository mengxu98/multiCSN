# Legacy dynamic windowing wrapper

Legacy dynamic windowing wrapper

## Usage

``` r
dynamic_windowing(
  meta_data,
  pseudotime_column = "pseudotime",
  group_column = "cluster"
)
```

## Arguments

- meta_data:

  Metadata data.frame.

- pseudotime_column:

  Pseudotime column.

- group_column:

  Group column.

## Value

Named list of state cells.
